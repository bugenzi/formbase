# Changelog

## 0.1.0 (2026-03-16)

### Features

- PDF form field editor with 6 field types: text, signature, initials, date, checkbox, dropdown
- CoordEngine for PDF/screen/relative coordinate conversion with Y-flip
- Zustand store with immer patch-based undo/redo
- interact.js drag & resize with snap-to-grid and alignment guides
- AcroForm PDF export via pdf-lib
- JSON schema export/import (FormSchema v2.0)
- AI field detection pipeline (vision-based, server-side proxy)
- AI chat panel for form assistance
- Keyboard shortcuts (T/S/D/C field add, Ctrl+Z undo, Delete remove, Escape deselect)
- Field palette with click-to-add and drag-to-page
- Properties panel with label, type, assignee, required, position editing
- PDF URL and File loading with drag-drop support
- IntersectionObserver-based lazy page rendering
- Error boundary with recovery UI
- Toast notification system
- Composable API — use full editor or individual components
