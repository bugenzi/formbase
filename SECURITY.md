# Security Policy

## Reporting a vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Use GitHub private vulnerability reporting or a private GitHub security advisory if it is enabled for this repository.
If private reporting is not available, contact the maintainer privately through GitHub.

Include:

- a short summary of the issue
- affected files, packages, or workflows
- reproduction steps or proof of concept
- impact assessment, if known
- any suggested remediation, if you have one

We will try to validate and address legitimate reports as quickly as possible.
